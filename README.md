# VeteriSoft — Centro de documentación

Sitio estático del proyecto VeteriSoft, organizado a partir de la documentación disponible.

## Publicación

GitHub Actions publica el contenido de `dist/` en GitHub Pages al actualizar `main`. Si la primera ejecución indica que Pages no está habilitado, configura **Settings → Pages → Build and deployment → Source → GitHub Actions** y vuelve a ejecutar el workflow `Deploy VeteriSoft documentation to GitHub Pages`.

## Copia pública

La portada y los documentos incluidos fueron preparados para esta publicación. Se retiró la sección editorial indicada y se excluyeron páginas con información personal de desempeño, enlaces a espacios privados y material relacionado. La copia mantiene 16 documentos y su portada.
